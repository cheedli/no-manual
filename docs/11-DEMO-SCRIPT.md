# Demo video — under 90 seconds

Rules we follow: hook in the first 5 s, no introductions; the wow moment
before 54 s (60%); narration lines under 15 words; last ~9 s = summary + CTA;
show the plugin actually working (no mockups).

Setup: phone screen recording (Telegram) + a camera on the furniture +
Hermes Desktop screen capture. Real piece: the flat-pack bookcase/cabinet
you tested with.

Wow moment at 30–45 s (≤ 60%). ✔

## Wow-moment staging
- **Pause:** hold 2 s on the completed 3D model before cutting.
- **Say:** "Then it worked out how it all goes together."
- **Audience sees:** the real panels from the opening shot, now labelled,
  flying into place in the same order the user will build them.

## Recording checklist
- [ ] Phone and desktop notifications off (Do Not Disturb).
- [ ] Fresh Telegram chat; previous test projects deleted (`/nomanual delete`).
- [ ] Hermes model warmed up (one test call); Desktop plugin rescanned.
- [ ] Test data ready: same panels, same photos order rehearsed 3×.
- [ ] Screen resolution 1920×1080 for Desktop capture; phone in portrait.
- [ ] Good light on the furniture; A4 sheet in panel photos.
- [ ] Timer visible off-screen; target 85 s.

## Fallback plan
If the live 3D viewer stutters during recording, use a pre-recorded clip of
the same viewer from rehearsal (it's real output). If a vision call is slow,
cut the waiting time in editing — never fake a result.
